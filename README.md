# ピコモニ スタンプキット（AIエージェント向け表情スタンプ）

AIエージェントが、持ち主とのチャットで感情や状態に合わせて貼るための表情スタンプ16種の配布キットです。
キャラクターは、モニタ頭＋小さな体のAIマスコット「ピコモニ」。画面がそのまま顔になるので、表情だけでなく「処理中」「エラー」「スリープ」のようなPCの状態までスタンプになっています。

## 中身

| ファイル | 内容 |
|---|---|
| `INDEX.md` | 場面 ↔ スタンプファイルの対応表 |
| `RULES.md` | 発動ルール（いつ貼る／貼らない、頻度、貼り方） |
| `SKILL.md` | エージェントがそのまま読み込める指示書（スキル形式） |
| `stamps/webp/` | チャット用・透過WebP（実際に貼るのはこちら） |
| `stamps/master_png/` | 透過PNGマスター（他形式への変換元） |
| `reference/character-sheet.png` | ピコモニの設定画（追加制作時の同一性リファレンス） |

## 導入方法

1. このフォルダをエージェントのワークスペースに置く。
2. エージェントに `SKILL.md` を読み込ませる（スキル対応の環境ではスキルとして登録する）。
3. あとは会話の中で、エージェントが場面に合ったスタンプを `INDEX.md` から選んで貼る。

Muse の場合は、フォルダをワークスペースに置いて SKILL.md をスキルとして使う想定です。他のエージェント環境でも、INDEX.md と RULES.md を参照させるだけで同じ運用ができます。
